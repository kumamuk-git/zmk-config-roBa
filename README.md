## WORK layer

Hold the left inner `:` key to enter WORK; tapping it still sends `:`. WORK
uses the left half only and emits shared macOS Hyper shortcuts. The right half
is transparent so the trackball remains in normal pointer mode.

```text
Hyper+H  Hyper+V  Hyper+M  Hyper+K  Hyper+L
—        Hyper+B  Hyper+P  Hyper+F  —
—        Hyper+C  Hyper+T  Hyper+E  —
```

The command positions follow the existing NUM layer: 1 ChatGPT, 2 Terminal,
3 Editor, 4 Browser, 5 Project, 6 Files, 7 Clipboard, 8 Voice, and 9 Maximize.
